# Crie seu primeiro jogo de plataforma 2D na Godot 4.2

![Capa do jogo](/img/godot_capa.png)

Bem-vindo(a)! Este curso é um passo a passo para você construir, do zero, um
**jogo de plataforma 2D** na **Godot Engine 4.2** com a linguagem **GDScript**.

No jogo, uma **laranja** precisa chegar ao fim de cada nível enfrentando diferentes
inimigos para reencontrar outras laranjas como ela. Simples no conceito, mas um
excelente primeiro projeto para aprender desenvolvimento de jogos 2D.

:::note Sobre a versão da Godot
Este material foi escrito para a **Godot 4.2**. A engine evoluiu desde então, mas
como ainda estamos na linha **4.x**, praticamente tudo aqui continua válido — pode
haver pequenas diferenças de interface em versões mais novas.
:::

## Como estudar

Cada capítulo constrói uma peça importante do jogo, de forma isolada e didática —
propositalmente **mais simples** que o projeto final, para que você entenda cada
conceito antes de juntar tudo:

- [**Parte 1 — O Personagem**](/godot/parte-1-personagem): monte a laranja, com
  animações, física de pulo caprichada e detecção de dano.
- [**Parte 2 — As Plataformas**](/godot/parte-2-plataformas): plataformas fixas,
  que caem, que se movem — e uma bônus.
- [**Parte 3 — Os Coletáveis**](/godot/parte-3-coletaveis): moedas com partículas e
  um baú que só abre com a chave certa.
- [**Parte 4 — O Inimigo Esqueleto**](/godot/parte-4-inimigo-esqueleto): um inimigo
  com máquina de estados — patrulha, ataca, se machuca, "morre" e ressuscita.

## Antes de começar

Você vai precisar da Godot instalada. Se ainda não tem, [baixe a Godot 4.2 aqui](https://godotengine.org/download/windows/).
Com a engine aberta, é só importar o projeto e começar a experimentar.

:::tip Aprender fazendo
Este é um **projeto de estudo** — feito para ensinar e para ser modificado. Sinta-se
livre para acrescentar, alterar e aperfeiçoar cada peça enquanto aprende. É assim que
o conhecimento gruda. 😉
:::
